# System status

Implemented:

- extraction rename and typed contracts for five modalities
- benchmark/runtime shared registries and strategies
- exact-offset chunking, embedding contracts, hybrid retrieval, reranking, and token-budget packing
- manifest-protected Chroma runtime with atomic logical-document replacement
- thin Streamlit/local FastAPI adapters
- deterministic smoke datasets, statistical harness, reports, and blinded-review workflow
- package-owned defaults, dependency extras/lock snapshot, and optional MLflow tracking

Pending external evidence:

- preparation of licensed standard/full extraction corpora and frozen QASPER manifests
- installation and digest/revision pinning of every optional candidate
- authoritative multi-hour/overnight runs on the target machine
- 60 blinded human judgments and one locked-test evaluation

Therefore no new model, extraction engine, or final RAG stack is yet claimed as the quality winner. The recommendation manifest remains non-authoritative and Chroma remains the temporary runtime backend.
