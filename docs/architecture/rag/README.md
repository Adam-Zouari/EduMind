# RAG architecture

The RAG package owns offset-preserving chunks, model-specific embedding contracts, manifest-protected indexes, dense/BM25/RRF retrieval, reranking, context packing, and cited local generation. The maintained guide is [`src/edumind/rag/doc.md`](../../../src/edumind/rag/doc.md).

Runtime defaults are recommendation-manifest driven and remain provisional until standard benchmarks, human review, and the locked test complete.
